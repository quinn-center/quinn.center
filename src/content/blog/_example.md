Files whose name starts with an underscore are templates and never build. Copy this file to
`a-short-slug.md` in this folder; the file name becomes the URL, `/blog/a-short-slug/`.

Write in Markdown. Headings start at `##` (the page title is the `#`). Keep headings in sentence
case, and link with words rather than bare URLs.

## A heading

Body text. **Bold**, *italic*, [a link](https://quinn.center), and lists:

- two
